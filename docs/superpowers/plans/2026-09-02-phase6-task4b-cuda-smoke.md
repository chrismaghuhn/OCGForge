# Phase 6 Task 4B CUDA Smoke Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the runner, CLI, zero-step verification, and one later-gated CUDA execution path for the provisional PyTorch Task-4B behavior-cloning smoke without changing any game, Teacher, Phase-5, or BC semantics.

**Architecture:** tools/phase6/task4b_runner.py owns the complete attempt: clean-H_exec verification, CMake probe build, probe binary provenance, admitted TRAIN-only ordering, CUDA training, actual step count, GPU memory telemetry, canonical export, completion receipt, and execution reports. tools/phase6/task4b_cuda_smoke.py is a path-only launcher and cannot provide execution evidence. Existing Task-4A codecs, model, CUDA preflight, export, reload, and inference functions remain the semantic authority.

**Tech Stack:** Python 3.14, the repository's existing C++17/CMake corpus probe, standard-library JSON/hash/subprocess utilities, and the installed CUDA-enabled PyTorch runtime. No new dependency, framework, rules input, deck, Teacher implementation, or Task-5 code.

class Task4BSmokeError(RuntimeError):
    def __init__(
        self,
        code: str,
        message: str,
        *,
        report: "Task4BExecutionReportV1 | None" = None,
    ) -> None:
        super().__init__(message)
        self.code = code
        self.report = report

    @property
    def report_json(self) -> str:
        return self.report.to_json() if self.report is not None else str(self)


@dataclasses.dataclass
class _SuccessfulStepCounter:
    value: int = 0

    def mark_success(self) -> None:
        self.value += 1


def _apply_optimizer_update(
    optimizer: torch.optim.Optimizer,
    loss: torch.Tensor,
    counter: _SuccessfulStepCounter,
) -> None:
    loss.backward()
    optimizer.step()
    counter.mark_success()


def _ordered_train_samples(
    samples: Sequence[codec.CorpusSampleV1],
) -> tuple[codec.CorpusSampleV1, ...]:
    train = [sample for sample in samples if sample.partition == "train"]
    ordered = sorted(
        train,
        key=lambda sample: sample.bc_sample_identity.encode("utf-8"),
    )
    if not ordered:
        raise Task4BSmokeError(
            "EMPTY_TRAIN_PARTITION",
            "admitted corpus has no train samples",
        )
    return tuple(ordered)
~~~

_apply_optimizer_update must not catch or reinterpret optimizer exceptions.
The counter mutation must remain textually after optimizer.step().

def _canonical_source_root() -> Path:
    module_root = Path(__file__).resolve().parents[2]
    git_root = Path(
        _run_git(module_root, "rev-parse", "--show-toplevel")[0]
    ).resolve()
    if os.path.normcase(str(git_root)) != os.path.normcase(str(module_root)):
        raise Task4BSmokeError(
            "SOURCE_ROOT_MISMATCH",
            "runner is not executing from its canonical checkout",
        )
    return git_root


def _verify_clean_h_exec(source_root: Path) -> str:
    head = _run_git(source_root, "rev-parse", "HEAD")[0].strip()
    if re.fullmatch(r"[0-9a-f]{40}", head) is None:
        raise Task4BSmokeError(
            "INVALID_H_EXEC",
            "HEAD is not exactly 40 lowercase hexadecimal characters",
        )
    status = _run_git(
        source_root,
        "status",
        "--porcelain",
        "--untracked-files=all",
    )[0]
    if status != "":
        raise Task4BSmokeError("DIRTY_H_EXEC", "source checkout is not clean")
    return head
~~~

_verify_clean_h_exec is the first operation in run_task4b_smoke. Ignored
build/cache files remain allowed because Git porcelain does not report them.
Its returned value is the only value later used as
TrainingRunManifestV1.training_code_commit and corpus_probe_source_commit.
